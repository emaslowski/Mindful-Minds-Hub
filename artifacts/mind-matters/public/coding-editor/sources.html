The editor runs in a sandbox, with no account, cloud project saving, public sharing, or project-upload server. Save projects through File > Save to your computer. Built-in sprite, costume, and sound libraries may fetch public assets from assets.scratch.mit.edu. Network/hardware extensions are not provided in this classroom integration.
