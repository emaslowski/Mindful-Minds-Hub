# ASL alphabet illustrations

Source: [ASL alphabet, Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Asl_alphabet_gallaudet.svg).

Credit: Ds13 / Darren Stone; vectorized by Marnanel, derived from the
Gallaudet-TT font. The source file is released into the public domain.

`alphabet.svg` is the original source graphic. `A.svg` through `Z.svg` are
individual groups extracted from that graphic, with text letter labels removed
and view boxes cropped. Original handshape paths and movement arrows are retained.
These are sourced illustrations, not generated approximations.

J and Z require movement; static illustrations do not replace instruction in
those movements. Reference: [Lifeprint fingerspelling introduction](https://www.lifeprint.com/asl101/fingerspelling/fingerspelling.htm).
