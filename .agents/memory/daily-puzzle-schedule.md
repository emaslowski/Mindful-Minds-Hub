---
name: Daily puzzle schedule
description: Compatibility constraints for the school's shared daily word puzzle.
---

Keep the daily word schedule stable and use midnight America/New_York for everyone, including visitors in other timezones.

**Why:** The game promises one shared daily puzzle. Reordering or resizing the answer pool, or changing its day calculation, can silently change an already-started puzzle and invalidate locally saved guesses.

**How to apply:** Treat changes to the answer schedule as compatibility changes. If a new schedule is needed, version both it and saved-game keys together rather than applying new answers to existing saved boards.
