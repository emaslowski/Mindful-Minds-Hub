name: Language learning content
description: Scope and educational accuracy rules for the Language Corner's Spanish and ASL activities.
---

The Language Corner is a whole activity center, with Spanish and American Sign
Language as the main subjects, rather than just a greetings card.

**Why:** The user asked to make Language Corner more fun with language games,
specifically Spanish and Sign Language, and more activities.

**How to apply:** Keep the core activities playable on the site without requiring
external videos, student accounts, microphones, or cameras. Treat ASL as a full
language, not English spelled with hands or a universal sign language. Use
verified educational handshape illustrations rather than invented or
AI-generated signs. J and Z require movement and must not be tested as static
handshape questions. Spanish pronunciation must be optional, with an honest
fallback when the browser has no Spanish voice.

Provide a Sign Language Videos collection in the Language Corner with a matching
teacher publishing destination.

**Why:** The user asked for a spot where they can post Sign Language videos.

**How to apply:** Keep the existing language activities and ASL accuracy rules.
Use teacher-approved website editions for videos; uploads and draft saves alone
must not publish them.
