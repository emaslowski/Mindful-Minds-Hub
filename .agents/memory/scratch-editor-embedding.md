name: School coding restrictions
description: Why the coding playground should not be reintroduced without a new user request.
---

The user requested removing the whole coding playground because their school account blocked the editor through iboss.

**Why:** The feature was unusable in the school's filtered environment, including after switching to a locally hosted Scratch editor.

**How to apply:** Do not reintroduce the coding playground or a replacement external coding editor unless the user asks. If they revisit coding later, establish compatibility with the school filter before investing in another integration.
