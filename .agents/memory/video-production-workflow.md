name: Optional video production handoff
description: Teacher-approved projects can be handed to Video Producers for a private video upload and final teacher review.
---

The user wants an option, when agreeing a project can be published, to send it to the Video Producer Command Center and give the producers a place to upload a video.

**Why:** The user asked for an optional video-production step after editorial and teacher approval.

**How to apply:** Preserve the existing direct-publication option. Sending for video production approves the content without publishing it immediately. Uploads return to the teacher for a final decision; a producer's upload must not bypass teacher review or turn an unreviewed recording into public content. Production assignments are separate from the producers' own authored projects.
