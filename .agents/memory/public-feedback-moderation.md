name: Public feedback moderation
description: Teacher approval and reply policy for public page discussions and website reviews.
---

The user requested comment sections on every public content section, teacher review before comments or site reviews are posted, and the ability to reply to reviews.

**Why:** Student contributions must not become public before the teacher reviews them.

**How to apply:** Treat saving a teacher reply and approving a review as separate decisions. Keep private journal and gratitude pages outside public discussion threads; comments must never create a path for private wellness content to become public. Preserve the existing collaboration-board moderation rules.

Each individual video, article, and content item must have its own moderated discussion, not only a shared discussion for its page.

**Why:** The user explicitly expanded the comment requirement to “each video and article and piece of content” and repeated the need for teacher review replies and deletion.

**How to apply:** Keep item threads attached to stable content identities when moving or reusing an item on multiple pages. Keep page-level discussions separate, and never allow private or unpublished projects to acquire public discussions.

Reviews that were public before review moderation should remain visible.

**Why:** The user requested that all previously displayed reviews be restored after the new approval setting hid them.

**How to apply:** Preserve the public status of historical reviews when changing moderation. Restoring those reviews does not authorize publishing new pending submissions without teacher approval.

Teachers must be able to delete pending and already-published site reviews.

**Why:** The user explicitly requested review deletion in addition to approval and replies.

**How to apply:** Provide an explicit delete control for both statuses, confirm that the review and teacher reply are permanently removed, and remove published reviews from public results after deletion.

The public collaboration board is the Brightside Advice Column. The user wants a large homepage invitation: “Want to chat with your friends? Go to the Brightside Advice Column!”

**Why:** The user requested the prominent homepage entry so students can find a place to comment and connect.

**How to apply:** Keep the existing moderated board as that destination rather than introducing an unmoderated chat or a separate discussion system.

Opening a section must start at the top of the page, not at “Join the conversation.”

**Why:** The user repeated this navigation requirement after section links retained the previous page's scroll position near the comments.

**How to apply:** Reset scroll on public route changes while preserving intentional in-page anchor links. Keep discussions below each section's main content.
